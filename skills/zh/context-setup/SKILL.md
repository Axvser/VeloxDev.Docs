# 上下文确认

## 职责

确认所有必要的上下文

## 流程

1.基于MainSKILL_Path，推导CloudGlyph_Child_Git的值

2.Project_Root必须由用户提供

3.LanguageTargets_List必须由用户提供，且必须是LanguageMap_List的子集，若不是子集，告知用户需要编辑LanguageMap_List以支持用户指定的语言

4.识别项目涉及的技术栈（编程语言、框架、构建工具、包管理器等），不预设任何特定技术

5.可选接受用户提供的SKILL路径，若提供则加载对应SKILL

6. **检查 Wiki_Root 现有内容** — 扫描 Wiki_Root 下各语言目录的现有文件结构，记录已存在的页面树，明确哪些维度已有内容、哪些为空，并将该信息传给后续编写阶段。把已存在的页面一律视为**此前的有效产出**：在工作状态中记录其路径与所属维度，使后续阶段能就地更新，也让 Review 阶段的清理能区分「上次运行的有效产出」与「误建目录」。本步骤绝不删除任何内容——删除决定只发生在 Review 阶段，且只针对「既不在本次输出清单中、也不被 Feature Inventory 覆盖的上轮页面」。

7.汇总表给到用户，待其确认后可继续工作流
