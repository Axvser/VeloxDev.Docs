# 欢迎页

## 职责

从模板创建符合当前项目的欢迎页

## 约束

❌ 不允许修改既定布局，例如：擅自修改页面大小、擅自添加ScrollViewer包裹

✔ 原则上尽量不修改配色、动画效果，除非用户直接要求

✔ 允许修改文本内容

✔ 允许删减功能条目

⚙ **功能卡片本身就是链接——不是可选项。** 用 `<a class="feat-link" href="…">` 包裹卡片内容，使整张卡片可点击。目标指向**卡片所述功能在「快速开始」中的页面**；该功能若没有自己的快速开始页面，则以「快速开始」栏目概览页为目标。`href` 遵循【链接与导航】中的同语言跨页链接语法——从 `0_欢迎/index.md` 出发，其余顶层维度都在上层目录，例如 `../1_快速开始/index.md` 或 `../1_快速开始/00_用户注册/index.md`。目录名要带数字前缀，并按本 Wiki 真实目录树调整。卡片文字本身就是标签，链接不再添加任何可见文本。保留让链接不显形的 `.feat-link` 规则。

⚙ **整页就是模板正文，别的一律不要。** 首屏（标题、副标题、分隔线、工作流步骤、功能卡片）就是页面的全部。**严禁**在收尾 `</div>` 之后追加说明段落、表格、功能清单、"浏览文档"之类的栏目、仓库链接或任何其他块。那些内容属于「快速开始」「API」「SE 分析」的页面。

⚙ **不要圆点分隔的宣传语行。** 不要再添加形如 `· 无数据库 · 开源 · MIT` 的尾行（即模板原先的 `.glow-dot` 行）。这类声明要么并入某张卡片，要么不写。

## 输出位置

Wiki_Root/0_欢迎/index.md

## 模板选择

从【模板索引】表中按「适用时机」选择模板，默认使用「创建Wiki的欢迎页时」对应的模板。

模板有两种可用形态——优先使用第一种：

- **原始文件（首选）** — 当 `Templates/welcome-default.md` 与本 SKILL 同目录存在（安装器会把模块模板随 SKILL.md 一并分发）时，直接读取该文件取得模板正文，无需任何解码。
- **转义表格单元（兜底）** — 否则从【模板索引】行中还原该单元。该单元是 JSON 字符串字面量，其中 `|` 被转义为 `\|` 以保持 Markdown 表格合法。精确还原需三步：① 取原始单元文本；② 将每个 `\|` 替换为 `|`（若无则跳过）；③ 把结果按 JSON 字符串解析（`json.loads` / `JSON.parse`），得到含真实换行的模板正文。

使用步骤：

1. 取得模板正文 — 若存在 `Templates/welcome-default.md` 原始文件则直接读取，否则按上述兜底步骤解码表格单元
2. 根据当前项目修改文本内容、删减功能条目，写入【输出位置】
3. 全程遵守【约束】：不修改既定布局、原则上不改配色与动画
