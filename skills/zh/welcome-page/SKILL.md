# 欢迎页

## 职责

从模板创建符合当前项目的欢迎页

## 约束

❌ 不允许修改既定布局，例如：擅自修改页面大小、擅自添加ScrollViewer包裹

✔ 原则上尽量不修改配色、动画效果，除非用户直接要求

✔ 允许修改文本内容

✔ 允许删减功能条目

✔ 允许将功能卡片做成**可点击跳转**：用 `<a>` 包裹卡片内容，`href` 遵循【链接与导航】中的同语言跨页链接语法。从 `0_欢迎/index.md` 出发，同级顶层栏目在上层目录——例如 `<a href="../2_API/index.md">…</a>`；目录名（含数字前缀）按本 Wiki 真实目录树调整。不改布局、配色与动画。

## 输出位置

Wiki_Root/0_欢迎/index.md

## 模板选择

从【模板索引】表中按「适用时机」选择模板，默认使用「创建Wiki的欢迎页时」对应的模板。

模板有两种可用形态——优先使用第一种：

- **原始文件（首选）** — 当 `Templates/welcome-default.md` 与本 SKILL 同目录存在（安装器会把模块模板随 SKILL.md 一并分发）时，直接读取该文件取得模板正文，无需任何解码。
- **转义表格单元（兜底）** — 否则从【模板索引】行中还原该单元。该单元是 JSON 字符串字面量，其中 `|` 被转义为 `\|` 以保持 Markdown 表格合法。精确还原需三步：① 取原始单元文本；② 将每个 `\|` 替换为 `|`（若无则跳过）；③ 把结果按 JSON 字符串解析（`json.loads` / `JSON.parse`），得到含真实换行的模板正文。

使用步骤：

1. 取得模板正文 — 若存在 `Templates/welcome-default.md` 原始文件则直接读取，否则按上述兜底步骤解码表格单元
2. 根据当前项目修改文本内容、删减功能条目，写入【输出位置】
3. 全程遵守【约束】：不修改既定布局、原则上不改配色与动画
