# 智能体上下文与技能

编辑工作流的智能体需要两类知识：框架是什么（类型、命令、默认值），以及怎样完成一件多步骤的活（建节点、接槽枚举器、布局整张图）。VeloxDev 通过**上下文 provider** 与**技能子系统**分别提供这两类知识。

上下文分层渲染，让提示词保持稳定；技能是可开关的文档——随包嵌入或从磁盘发现——模型需要时才加载。

## 你会构建什么

- 配置了提示语言与自动发现的 scope；
- 为一个组件类型渲染出的 `[AgentContext]` 描述；
- 一个发现七个内置工作流技能、关闭其中一个并重建提示块的 `SkillScope`。

## 上下文与技能的分工

| 来源 | 携带什么 | 何时变化 |
|---|---|---|
| 静态骨架 | 行为约束、参考文档、类型目录 | 构造后从不 |
| 能力包络 | 闸门、被关掉的工具、预算、漂移 | 每次配置变更 |
| 技能 | 每篇文档一个流程，外加随附资源 | 每次开关技能 |
| MCP | 服务器清单与工具 | 每次装载服务器 |

骨架只渲染一次；另外三者每轮贡献。把每轮变化的内容塞进骨架，要么每轮重建一大段提示词，要么冻结住必须变化的文字。
