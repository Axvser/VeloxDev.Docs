# 运行与验证

编辑器通过六件事验证：渲染、拖拽、连接、平移、缩放与输入路由 —— 这些正是表面拥有的东西。

## 运行

```powershell
dotnet run
```

**预期结果：** 打开一个窗口，里面有三张节点卡与一条连线。小地图位于表面右上角。

## 检查什么

1. **拖动节点卡。** 节点跟随指针；插槽布局写回新锚点后，连线端点跟随。
2. **按下一个端口，在另一个端口松开。** 建成连线。在空白画布松开则取消预览。
3. **Ctrl+滚轮。** 指针下的点保持不动，画布缩放。手势夹取在 `[0.1, 10]`。
4. **缩到约 40%。** 连线必须仍然接在端口上；几乎所有连线缺陷在 100% 下都看不见。
5. **Ctrl+Z / Ctrl+Y。** 结构改动撤销与重做。已完成的拖动不在历史里。
6. **Shift+滚轮。** 表面横向滚动。普通滚轮竖向滚动。
7. **右键连线。** `Delete` 条目把它删掉。

**预期结果：** 每一步之后表面都保持一致；没有连线脱落，小地图的视口块跟随滚动。
