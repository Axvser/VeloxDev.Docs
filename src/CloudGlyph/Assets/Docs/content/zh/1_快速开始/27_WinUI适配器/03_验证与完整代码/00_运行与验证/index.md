# 运行与验证

运行 Windows 目标，并逐项练习下面的交互。

## 运行

```powershell
dotnet run
```

**预期结果：** 打开一个非打包 WinUI 窗口，里面有三张节点卡与一条连线；小地图位于表面右上角。

## 检查什么

1. **拖动卡片。** 节点移动；连线跟随测量到的插槽锚点。
2. **按下一个端口，在另一个端口松开。** 建成连线；在空白画布松开则取消。
3. **Ctrl+滚轮。** 指针始终停在同一个世界点上，画布缩放；`Scale` 夹在 `[0.1, 10]`。
4. **缩到约 40%。** 连线必须仍然接在端口上。这正是偏移帧存在的检查；深缩放下消失或脱落的连线是裁剪缺陷，不是数据缺陷。
5. **Ctrl+Z / Ctrl+Y。** 结构改动撤销与重做。
6. **Shift+滚轮。** 表面横向滚动。
7. **右键连线。** 原生浮出菜单的 `Delete` 条目删掉那条线。

**预期结果：** 没有连线脱落，深缩放下没有连线消失，小地图跟随滚动。

## 如果画布是空的

表面通过 `UserControl` 的名字域解析 `PART_*`。代码搭建的表面必须注册名字并调用 `WorkflowSurfaceBehavior.Refresh(host)`；换宿主或换模板后漏掉 `Refresh`，解析会停在旧状态。WinUI 的表面正是为此暴露 `Refresh` 的那一家。

**预期结果：** `Refresh` 之后，画布变换与网格装饰器拿到相同的内容偏移，节点池开始物化视图。
