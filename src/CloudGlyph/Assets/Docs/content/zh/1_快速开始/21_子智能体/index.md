# 子智能体

`SubAgentScope` 让智能体派出后台子代理。每个子代理都是同一棵树上的完整工作流智能体，持有父级能力的一个切片。派发方式是**派出后轮询**：spawn 立刻返回句柄，子代理在句柄后面运行——因为 spawn 发生在宿主 UI 线程上的一次工具调用里，同步子代理会把那条线程占满整个对话。

子代理的额度是父级账本的一份份额，不是另一口锅。这正是无限深度能够终止的原因，也是根上限就是整棵树上限的原因。

## 你会构建什么

- 从聊天客户端建立的 `SubAgentScope`，带深度限制与 spawn 预算；
- 模型调用的五个派发工具；
- 操作者查看的名册，既有可绑定行，也有线程安全快照。
