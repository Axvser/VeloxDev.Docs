# 工作流运行时

`RuntimeEngine.RunAsync` 驱动的是 `CompiledGraph`，不是实时画布：它逐段遍历编译产物，调用每个节点的 `ReceiveAsync`，并把返回值写进会话供下一个节点读取。图决定形状，引擎决定路径、载荷和运行的收尾方式。

三页递进：

- [执行编译图](00_执行编译图/index.md)——链、带键汇合的扇出、数据流、日志与运行结局。
- [重试与重定向](01_重试与重定向/index.md)——抛出的失败、`IRedirectable`、错误接收器与补偿。
- [暂停、观察与检查点](02_暂停观察与检查点/index.md)——执行门、观察者、文件日志写入器，以及从检查点恢复。

三页使用同一张编译图。所有能力都是可选的，配置在 `RuntimeContext` 上；一项都不配时，运行行为与从前完全一致。
