# 平台适配器契约

VeloxDev.Core 拥有每个 GUI 适配器都要闭合的那套表面：一条输入路由、一组滚动与导航能力、一份网格/小地图数据交换、一个视图池组合。`Src/Adapters/` 下的七个适配器都是这套表面的实现，没有哪一家另起一套。

本 QuickStart 用代码搭出一个 WPF 表面来跟随这套契约，因此不打开窗口也能观察到共享行为。下面的断言，就是无头一致性套件在 WPF、Avalonia、WinForms、Razor 与 Jalium 上驱动的那一组。

## 页面

- [前置条件](00_前置条件/index.md) —— 支持的目标、包与工具。
- [命名部件](01_命名部件/index.md) —— 七个角色与绑定它们的附着属性名。
- [输入与表面契约](02_输入与表面契约/index.md) —— 输入路由、滚动/导航能力、表面度量与视图池。
- [一致性验证](03_一致性验证/index.md) —— 共享 `TestGraph`、可运行的契约测试与无头套件。
