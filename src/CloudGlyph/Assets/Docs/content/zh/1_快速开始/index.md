# 快速开始

每个 VeloxDev 功能的手把手指南。每页都从空项目开始，带你一步步构建一个**可运行的程序**，给出精确的 SDK/运行时版本、每一步可观察的**预期结果**，并在结尾附上诚实的**运行声明**。

VeloxDev 是一组 .NET 库，用于在任意 .NET GUI 上构建**可由 AI 控制的工作流编辑器**。先从核心工作流引擎开始，再叠加 MVVM、动画、主题、AOP、MonoBehaviour 生命周期与 AI 代理。

| 功能 | 你将构建的内容 |
|---|---|
| [00 工作流系统](00_工作流系统) | 画布上的节点图：树、节点、槽、连接、撤销/重做、编译与运行 |
| [01 工作流代理](01_工作流代理) | 通过 60+ 工具与 MCP 服务器在运行时编辑工作流的 AI |
| [02 MVVM](02_MVVM) | 通过源生成器实现的可观察属性与异步命令 |
| [03 过渡动画](03_过渡动画) | 流畅的属性插值与缓动 |
| [04 动态主题](04_动态主题) | 带过渡动画的运行时主题切换 |
| [05 AOP](05_AOP) | 编译期切面代理 |
| [06 MonoBehaviour](06_MonoBehaviour) | 帧驱动生命周期循环 |
| [07 弱引用类型](07_弱引用类型) | 弱集合与弱委托 |
| [08 平台适配器](08_平台适配器) | GUI 适配器与 `dotnet new` 视图模板 |

## 通用前置条件

- .NET SDK **8.0.400+**（示例面向 `net9.0`；库多目标 `netstandard2.0` / `net6.0` / `net9.0`）。
- 已安装所选适配器的 GUI 工作负载（WPF / Avalonia / WinUI / MAUI / WinForms / Razor）。
- 可访问 NuGet 以还原 `VeloxDev.*` 包。
