# 运行与验证

运行桌面目标，并逐项练习下面的交互。

## 运行

```powershell
dotnet run
```

**预期结果：** 打开一个桌面窗口，里面有三张节点卡与一条连线；小地图位于表面右上角。

## 检查什么

1. **拖动卡片。** 节点移动，连线跟随测量到的插槽锚点。
2. **按下一个端口，在另一个端口松开。** 建成连线；在空白画布松开则取消。
3. **Ctrl+滚轮。** 指针下的点保持不动；适配器把 `Scale` 夹在 `[0.1, 10]`。
4. **缩到约 40%。** 连线必须仍然接在端口上。
5. **Ctrl+Z / Ctrl+Y。** 结构改动撤销与重做；拖动不在历史里。
6. **Shift+滚轮。** 表面横向滚动。
7. **右键连线。** `Delete` 条目删掉那条线。

**预期结果：** 每一步之后表面都保持一致；没有连线脱落，小地图跟随滚动。
