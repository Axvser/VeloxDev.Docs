# 运行与验证

运行 Windows 目标，并逐项练习下面的交互。

## 运行

```powershell
dotnet build -t:Run -f net10.0-windows10.0.19041.0
```

**预期结果：** 打包的 Windows MAUI 应用启动，显示三张节点卡与一条连线，小地图位于表面右上角。

## 检查什么

1. **拖动卡片。** 节点移动；连线跟随测量到的插槽锚点。
2. **按下一个端口，在另一个端口松开。** 建成连线；在空白画布松开则取消。
3. **Ctrl+滚轮。** 指针始终停在同一个世界点上，画布缩放。
4. **缩到约 40%。** 连线必须仍然接在端口上。覆盖层做成视口尺寸，正是为了扛住深缩放；整层消失就是撞上了 Win2D 纹理上限。
5. **悬停连线并按 Delete。** 连线被删除。如果悬停毫无反应，先查 `InteractionSource`。
6. **Shift+滚轮。** 表面横向滚动。
7. **右键连线。** `Delete` 条目删掉那条线。
8. **点击小地图。** 视口重新居中到按下的点。

**预期结果：** 每一步之后表面都保持一致，覆盖层的连线在深缩放下仍然接住端口。
