# AOP、MonoBehaviour 与弱引用 — API 参考

## AOP (VeloxDev.AspectOriented)

| 类型 | 描述 |
|------|-------------|
| Aop | 代理到目标的逆向查找 |
| IAspectOriented | 标记类以生成 AOP 代理 |

## MonoBehaviour (VeloxDev.TimeLine)

| 类型 | 描述 |
|------|-------------|
| MonoBehaviourAttribute | 标记类 |
| MonoBehaviourManager | 管理生命周期 |

## WeakTypes (VeloxDev.WeakTypes)

| 类型 | 描述 |
|------|-------------|
| WeakCache<TKey, TValue> | 弱引用字典 |
| WeakQueue<T> | 弱引用队列 |
| WeakStack<T> | 弱引用栈 |
| WeakDelegate<T> | 弱引用事件处理 |
