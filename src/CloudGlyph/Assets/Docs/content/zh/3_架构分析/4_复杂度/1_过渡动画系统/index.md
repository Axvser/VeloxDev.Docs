# 复杂度分析 — 过渡动画系统

## 代码规模

| 组件 | 文件数 | 代码行数 |
|---|---|---|
| 缓动函数 | 1 | ~240 |
| 核心抽象 | 10 | ~800 |
| 原生插值器 | 15 | ~450 |
| 状态/过渡 | 6 | ~600 |
| 调度器 | 2 | ~300 |
| **小计（核心）** | **~34** | **~2,400** |
| 测试 | 5 | ~450 |
| 平台适配器（每平台） | ~15 | ~600 |

## 插值器性能

| 操作 | 复杂度 |
|---|---|
| RegisterInterpolator | O(1) |
| TryGetInterpolator | O(1) |
| Interpolate（线性） | O(steps) |
| Ease 计算 | O(1) |
