# 功能地图

VeloxDev 所有功能模块的职责映射。

| 模块 | 描述 |
|---|---|
| [工作流系统](0_工作流系统) | Tree、Node、Slot、Link、空间索引、编译 |
| [过渡动画系统](1_过渡动画系统) | 缓动函数、插值器、调度器 |
| [动态主题](2_动态主题) | 主题定义、动画切换 |
| [MVVM](3_MVVM) | VeloxCommand、VeloxProperty |
| [AOP、MonoBehaviour 与 WeakTypes](4_AOP与MonoBehaviour与弱引用) | AOP、TimeLine、弱引用集合 |
