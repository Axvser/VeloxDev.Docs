# 03 · 数据流分析

每个功能核心 API 调用链的 PlantUML 时序图。每页覆盖正常流程、错误/异常路径，以及（适用时的）异步/事件驱动场景。

| 功能 | 核心流程 |
|---|---|
| [00 工作流系统](00_工作流系统) | 创建节点 → 连接 → 接收/广播 → 撤销/重做 → 编译与运行 → 序列化 |
| [01 工作流代理](01_工作流代理) | 代理工具调用 → 变更 → 状态差异 → 确认；MCP stdio 握手 |
| [02 MVVM](02_MVVM) | 命令入队 → 开始 → 完成/取消/失败 → 退出 |
| [03 过渡动画](03_过渡动画) | 快照 → 调度 → 逐帧插值 → 应用 → 完成 |
| [04 动态主题](04_动态主题) | 注册 → 过渡 → 插值主题属性 → 主题已更改 |
| [05 AOP](05_AOP) | CreateProxy → 设置钩子 → 调用 → 开始/覆盖/结束链 |
| [06 MonoBehaviour](06_MonoBehaviour) | 启动通道 → 更新/晚更新/固定更新 tick → 停止 |
| [07 弱引用类型](07_弱引用类型) | 入队/压栈 → 访问时清扫 → 出队/出栈 |
| [08 平台适配器](08_平台适配器) | 附加行为接线 → 拖拽/连接 → 视图池虚拟化 |
