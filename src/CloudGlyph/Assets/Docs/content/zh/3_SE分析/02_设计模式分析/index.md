# 02 · 设计模式分析

每个功能的设计模式分析。下面的每一页都记录了该功能所采用的模式——附有展示接口、基类与具体实现的 Mermaid `classDiagram` 类图，以及描述每个模式及其出现位置的表。

| 功能 | 关键模式 |
|---|---|
| [00 工作流系统](00_工作流系统) | 命令 / 撤销重做、模板方法、观察者、策略（编译期 Static/Dynamic + 运行期重定向）、代理 / 装饰器、门面、组合、虚拟代理 |
| [01 工作流代理](01_工作流代理) | 构建者、门面、命令、备忘录、装饰器、适配器、观察者、策略 |
| [02 MVVM](02_MVVM) | 命令、可观察属性、源生成器模板 |
| [03 过渡动画](03_过渡动画) | 流式构建器 + 链、注册表、策略（缓动 + ISampler）、模板方法、适配器、调度器 + CWT 缓存、组合、观察者 |
| [04 动态主题](04_动态主题) | 门面、弱引用注册表、缓存、策略（`StartModel` + 采样器）、模板方法（生成器）、适配器/桥接（平台转换器） |
| [05 AOP](05_AOP) | 代理、装饰器、拦截器 |
| [06 MonoBehaviour](06_MonoBehaviour) | 生命周期钩子 / 模板方法、发布-订阅 |
| [07 弱引用类型](07_弱引用类型) | 弱引用、访问时清扫 |
| [08 平台适配器](08_平台适配器) | 适配器、附加行为、对象池、命令、策略 / 桥接、观察者 |
