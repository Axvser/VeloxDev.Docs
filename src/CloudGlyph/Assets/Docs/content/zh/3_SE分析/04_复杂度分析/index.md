# 04 · 复杂度分析

使用 KaTeX 公式分析每个功能核心操作的时间与空间复杂度。每页覆盖构造、执行、查找、序列化与内存占用。

| 功能 | 代表性界限 |
|---|---|
| [00 工作流系统](00_工作流系统) | 空间哈希查询、空间虚拟化、编译（正向 / 反向锥）、顺序执行与重定向、汇合、撤销/重做、序列化 |
| [01 工作流代理](01_工作流代理) | 自动发现扫描、JSON 快照差异、工具分发、Root/Terminal 编译 + 运行 |
| [02 MVVM](02_MVVM) | 命令排队（信号量）、属性通知 |
| [03 过渡动画](03_过渡动画) | 属性路径解析、路径冲突检查、采样器准备、每帧插值、调度器扇出 |
| [04 动态主题](04_动态主题) | 主题查找、按实例活动缓存 |
| [05 AOP](05_AOP) | 代理调用分发、`AopCache` 解析 |
| [06 MonoBehaviour](06_MonoBehaviour) | 每帧行为分发、固定更新间隔 |
| [07 弱引用类型](07_弱引用类型) | 访问时清扫、自适应清理阈值 |
| [08 平台适配器](08_平台适配器) | 视图池复用、空间虚拟化、缩放折叠、小地图投影 |
