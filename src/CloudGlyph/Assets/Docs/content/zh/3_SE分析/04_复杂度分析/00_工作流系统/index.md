## 两种有界形状

本特性里几乎每个代价都落在下面两种形状之一，认出某个操作属于哪种，多半就知道该关心什么：

- **对元素数量是 `O(1)`，对几何是 `O(cells)`。** 空间索引与虚拟化那一趟取决于视野里有多少*空间*，而不是图里有多少节点。图大十倍而视野不变，每帧的代价不变。
- **对图是 `O(V + E)` 或 `O(N)`。** 编译、执行、检查点快照与大纲都只对每个节点（编译时还包括每条边）做有界的若干次访问。这里没有对图超线性的东西，而两处可能超线性的 —— 扇出组与重定向 —— 各自都有上限（`MaxParallelBranches`、`MaxRedirects = 50`）。
