# 08 · 平台适配器 — 复杂度分析

平台适配器核心操作的时间与空间复杂度。界限以 WPF 适配器源码和演示为依据；未经演示覆盖的内容以源码推断并标注 `*推断所得*`。设 $N$ = 节点总数、$V$ = 可见节点数、$P$ = 池化视图数、$b$ = 批次大小。

## `ViewPool` / `ViewManager` 复用与虚拟化

`ViewManager` 为每个类型维护一个视图队列。可见项要么命中池（出队 + 重新绑定），要么（每类型一次）执行 `template.LoadContent()`。

| 操作 | 开销 | 说明 |
|---|---|---|
| 实例化一个可见项 | 摊还 $O(1)$ | 有池命中时；否则实例化模板（每类型只付一次） |
| 隐藏一项（从 `VisibleItems` 移除） | $O(1)$ | 折叠 + 清空 `DataContext` + 入池 |
| 分批刷新 | 每 dispatcher 滴答 $O(b)$ | $b = 3$（WPF 已验证）；每帧渲染预算保持有界 |
| 全部重置 | $O(A)$ | $A$ = 活动视图数；逐个折叠并重新入池 |
| 模板查找 | 摊还 $O(1)$ | `_templateMap` 缓存；首次未命中时遍历资源 |

因为视图被复用而非销毁，每次增删的稳态分配为摊还 $O(1)$，平移/缩放大型图时对 GC 的压力有界。

## 小地图投影

`WorkflowMinimapOverlay.RefreshMinimapData` 仅在标记为脏时对全部节点包围盒求并：

$$b_w = \max_i(n_{x,i} + n_{w,i}) - \min_i(n_{x,i}), \qquad O(N)\ \text{仅脏时}$$

每个可见节点矩形在渲染时的投影为 $O(1)$：

$$x_i = o_x + (n_{x,i} - b_l)\,s, \qquad y_i = o_y + (n_{y,i} - b_t)\,s$$

其中比例

$$s = \min\!\left(\frac{d_w}{b_w},\ \frac{d_h}{b_h}\right)$$

拖拽视口指示框以 $O(1)$ 映射回世界坐标并滚动视图：

$$w_{cx} = \frac{a_x - o_x}{s} + b_l, \qquad scroll_x = w_{cx} - \frac{v_w}{2} + c_x$$

| 操作 | 开销 |
|---|---|
| 全局包围盒刷新（脏时） | $O(N)$ |
| 每帧渲染节点矩形 | $O(V)$ — 每个矩形 $O(1)$ |
| 视口指示框拖拽 → 滚动 | $O(1)$ |

## `WorkflowSurfaceBehavior` 平移 / 缩放变换

平移期间的每次鼠标移动都是 $O(1)$：计算候选偏移、按滚动上限夹取、在边缘增长 `Layout.NegativeOffset`/`PositiveOffset`，然后两次 `ScrollTo*` 调用和一次写入 `Helper.Viewport` 的 `UpdateVisibleRegion`。

| 操作 | 开销 |
|---|---|
| 每次平移滴答（鼠标移动） | $O(1)$ |
| 滚动变化 → 可见区域更新 | $O(1)$ |
| 边缘布局增长 | 每次事件 $O(1)$；只在布局失效时才强制 `ScrollViewer` 对增大的 `Canvas` 重新度量 |

平移/缩放变换是单个 `TranslateTransform`，通过 `WorkflowCanvasTransformBehavior` 应用；节点/连接视图每帧渲染时读取一次，因此变换本身不增加每节点簿记开销。

## 每帧渲染：可见 vs 总数

没有池时渲染是 $O(N)$。把 `ViewPool` 绑定到 `Helper.VisibleItems` 后，只实例化可见子集：

$$R_{\text{frame}} = O(V), \qquad V \ll N \text{（大图时）}$$

| 指标 | 界限 |
|---|---|
| 每帧渲染 | $O(V)$ — 仅可见项 |
| 活动视图内存 | $O(V)$ |
| 池化视图内存 | $O(P)$（回收的视图保留待复用） |
| 每帧分配 | 摊还 $O(b)$（$b=3$）— 无论 $N$ 多大都有界 |
| 小地图每帧渲染 | $O(V)$ 个节点矩形，每个 $O(1)$ |

## 总结

适配器层让每帧开销正比于屏幕上可见的内容，而非图中全部内容：虚拟化把渲染限制在 $V$，视图池把每帧分配限制为小批量，小地图在仅脏时 $O(N)$ 求一次包围盒后每个可见节点以 $O(1)$ 投影。平移路径每次输入事件为 $O(1)$。
