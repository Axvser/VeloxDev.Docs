# MonoBehaviour — API 参考

命名空间 `VeloxDev.TimeLine` 托管帧循环管理器及其事件参数类型；`VeloxDev.MonoBehaviour` 托管 `IMonoBehaviour` 契约。两者都随 `VeloxDev.Core` 包分发。证据来源：源码（`Src/Core/VeloxDev.Core/TimeLine/`、`.../Interfaces/MonoBehaviour/`）、源生成器（`Src/Generators/VeloxDev.Core.Generator/`）、WPF 示例（`Examples/MonoBehaviour/WPF/Demo/`）与 MSTest 测试套件（`Src/Core/VeloxDev.Core.Test/TimeLine/`）。
