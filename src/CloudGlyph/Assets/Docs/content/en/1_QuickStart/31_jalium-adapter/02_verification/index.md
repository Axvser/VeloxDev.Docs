# Verification and complete code

## Wire the entry point

The desktop host needs an `AppBuilder`. `Program.cs`:

```csharp
using Jalium.UI;

namespace MyWorkflowApp;

internal static class Program
{
    [STAThread]
    private static int Main(string[] args)
    {
        var builder = AppBuilder.CreateBuilder(new AppBuilderSettings
        {
            Args = args,
            DisableDefaults = true
        });

        builder.ConfigureApplication(app => app.MainWindow = new MainWindow());

        using var host = builder.Build();
        return host.Run();
    }
}
```

`DisableDefaults` skips the hosting defaults the demo does not need; remove it if your app uses them.

## Run it

```powershell
dotnet run
```

**Expected result**, in order:

1. The window opens to a world grid with floating top/left ruler bands.
2. Two 260×180 cards and the link between them are visible.
3. Dragging the card's title bar moves the card; dragging blank surface pans.
4. Ctrl+wheel zooms around the viewport centre; zooming in *decreases* `Scale` (`Scale *= 1 / 1.1`).
5. Dragging from a port starts a rubber band; releasing on the other card's legal port creates a second link.
6. Right-pressing a link opens the `LinkContextMenu`; the template ships it empty, so add a `MenuItem` bound to `DeleteCommand` to see a Delete entry.
7. At 40% zoom the link still reaches both ports and is still drawn.

## Two Jalium traps to check first

- **Cards sit at the world origin after a pan.** The `CanvasTransform` mirror is missing from the tree code-behind, or the node/link template binds the attached property instead of the plain `CanvasTransform`. The translation is never applied and nothing errors.
- **Links disappear at deep zoom.** `LinkView` stopped calling `WorkflowLinkBounds.Apply`; its layout box no longer covers the curve, and Jalium's renderer drops it. Hit testing also regresses, because the view publishes the curve from the same pass.

A normal wheel is routed through `WorkflowInput.Scroller`; only Ctrl+wheel is the zoom gesture. Panning starts from a left-press on `PART_SurfaceBorder`, so a press that lands on a card or a port moves the node or begins a connection instead.

## Complete code

`Views/MainView.jalxaml.cs`. The four ViewModels and the seven generated roles are defined in [Surface and host](../01_surface-and-host/index.md).

```csharp
using Jalium.UI.Controls;
using MyWorkflowApp.ViewModels;
using VeloxDev.WorkflowSystem;
using Size = VeloxDev.WorkflowSystem.Size;

namespace MyWorkflowApp.Views;

public partial class MainView : UserControl
{
    public MainView()
    {
        InitializeComponent();

        var tree = new TreeViewModel();
        LoadSample(tree);
        DataContext = tree;
    }

    private static void LoadSample(TreeViewModel tree)
    {
        tree.Layout.NegativeOffset = new Offset(320, 260);
        var size = new Size(260, 180);

        var source = new NodeViewModel
        {
            Name = "Source",
            Size = size,
            Anchor = new Anchor { Horizontal = 0, Vertical = 0 }
        };
        var sink = new NodeViewModel
        {
            Name = "Sink",
            Size = size,
            Anchor = new Anchor { Horizontal = 360, Vertical = 0 }
        };

        tree.CreateNodeCommand.Execute(source);
        tree.CreateNodeCommand.Execute(sink);

        source.OutputSlots.SetSelector(typeof(bool));
        source.InputSlot.SetChannelCommand.Execute(SlotChannel.OneSource);
        sink.InputSlot.SetChannelCommand.Execute(SlotChannel.MultipleSources);

        if (source.OutputSlots.Items.FirstOrDefault()?.Slot is { } sender)
        {
            tree.Links.Add(new LinkDefaultViewModel
            {
                Sender = sender,
                Receiver = sink.InputSlot,
                IsVisible = true
            });
        }
    }
}
```

Symbol sources:

- `TreeViewModel`, `NodeViewModel`, `SlotViewModel`, `VirtualizeHelper` — [Surface and host](../01_surface-and-host/index.md).
- `TreeView`, `NodeView`, `SlotView`, `LinkView`, `TemplateSelector`, `GridDecorator`, `MinimapOverlay` — generated by `jalium-v-*`; mirror in `Examples/Workflow/Jalium Trimmed/Demo/Views/Workflow/`.
- `AppBuilder`, `AppBuilderSettings`, `UserControl` — `Jalium.UI`.
- `WorkflowLinkBounds`, `WorkflowSurfaceBehavior` — `Src/Adapters/VeloxDev.Jalium/WorkflowSystem/AttachedBehaviors/`.
