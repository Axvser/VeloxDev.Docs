# Razor Adapter

`VeloxDev.Razor` treats the workflow surface as a Blazor component tree. There is no canvas control and no attached properties: `WorkflowSurfaceBehavior` is a component whose `[Parameter]`s replace the attached properties of the desktop adapters, and a small JS module (`wwwroot/veloxdev.workflow.js`, shipped inside the package) owns the wheel gesture, element measurement and the zoom-frame curve refresh.

This quick start builds an Interactive Server page that renders two nodes, their ports and a link.

## What you will have at the end

- A Blazor Web App project targeting `net8.0` — the tested demo is `net10.0`.
- The seven view roles generated by `VeloxDev.Razor.Templates`, each a `.razor` + `.razor.cs` pair.
- A tree with two nodes, a channel-constrained input port and a visible link.
- Pan, wheel scroll, Ctrl+wheel zoom, node drag and slot connection checked in the browser.
