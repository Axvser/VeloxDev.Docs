# Verification and complete code

## Run it

```powershell
dotnet run
```

Open the HTTPS URL printed by the launcher and navigate to `/`.

**Expected result**, in order:

1. The surface fills the page with a world grid and top/left ruler bands.
2. Two node cards and the link between them are visible.
3. Dragging the card's title strip moves the card; the canvas does not pan.
4. Dragging blank surface pans, and the pointer stays over the same world point.
5. Ctrl+wheel zooms around the pointer; the card text, ports and link scale together.
6. Dragging from a port starts a rubber band; releasing on the other card's legal port creates a second link.
7. Right-pressing a link opens the menu you declared in `<LinkMenu>`.

## The link menu is empty by default

The generated `TreeView.razor` declares the menu fragment and adds no entries:

```razor
<LinkMenu Context="link">
</LinkMenu>
```

Each entry receives the right-pressed link, so one line is a complete action:

```razor
<LinkMenu Context="link">
    <button type="button" @onclick="() => link.DeleteCommand.Execute(null)">Delete</button>
</LinkMenu>
```

This GUI has no binding syntax for menu items, so the handler stays inline. The surface renders the menu chrome, positions it, and suspends the input router while it is open.

## Why the zoom needs the JS half

`ZoomEnabled` switches the component-side behaviour on; the non-passive `wheel` listener in `_content/VeloxDev.Razor/veloxdev.workflow.js` performs the zoom. After a zoom, the JS dispatches `veloxdev-wf-layout-changed` on the next animation frame and the slot layout listens for it to re-measure. A hand-written zoom path must dispatch the same event or the ports stay at their old positions while the cards move.

The wheel listener also hands plain wheel deltas to the server; the surface routes them through `WorkflowInput.Scroller` unless a subscriber refused the event.

## Complete code

`Components/Pages/Home.razor`. The four ViewModels are defined in [Surface and host](../01_surface-and-host/index.md); the generated components are the fourteen files from that page.

```razor
@page "/"
@rendermode RenderMode.InteractiveServer
@using VeloxDev.WorkflowSystem

<PageTitle>VeloxDev Workflow</PageTitle>

<div style="position:relative;width:100vw;height:100vh;">
    @if (_tree is not null)
    {
        <TreeView Tree="_tree" />
    }
</div>

@code {
    private TreeViewModel? _tree;

    protected override void OnInitialized()
    {
        _tree = new TreeViewModel();
        LoadSample(_tree);
    }

    private static void LoadSample(TreeViewModel tree)
    {
        tree.Layout.NegativeOffset = new Offset(320, 260);
        var size = new Size(260, 180);

        var source = new NodeViewModel
        {
            Name = "Source",
            Size = size,
            Anchor = new Anchor { Horizontal = 0, Vertical = 0 }
        };
        var sink = new NodeViewModel
        {
            Name = "Sink",
            Size = size,
            Anchor = new Anchor { Horizontal = 360, Vertical = 0 }
        };

        tree.CreateNodeCommand.Execute(source);
        tree.CreateNodeCommand.Execute(sink);

        source.OutputSlots.SetSelector(typeof(bool));
        source.InputSlot.SetChannelCommand.Execute(SlotChannel.OneSource);
        sink.InputSlot.SetChannelCommand.Execute(SlotChannel.MultipleSources);

        if (source.OutputSlots.Items.FirstOrDefault()?.Slot is { } sender)
        {
            tree.Links.Add(new LinkDefaultViewModel
            {
                Sender = sender,
                Receiver = sink.InputSlot,
                IsVisible = true
            });
        }
    }
}
```

Symbol sources:

- `TreeViewModel`, `NodeViewModel`, `SlotViewModel`, `VirtualizeHelper` — [Surface and host](../01_surface-and-host/index.md).
- `TreeView`, `NodeView`, `SlotView`, `LinkView`, `TemplateSelector`, `GridDecorator`, `MinimapOverlay` — generated by `razor-v-*`; mirror in `Examples/Workflow/Blazor Trimmed/Demo/Components/Workflow/`.
- `WorkflowSurfaceBehavior`, `WorkflowPresentation` — `Src/Adapters/VeloxDev.Razor/WorkflowSystem/AttachedBehaviors/`.
