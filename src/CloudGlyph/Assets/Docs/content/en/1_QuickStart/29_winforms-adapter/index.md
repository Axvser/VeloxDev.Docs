# WinForms Adapter

`VeloxDev.WinForms` draws the workflow surface inside one Easel `VisualHost`. A single camera matrix scales the whole graph on `PART_Canvas`; the tree is a visual `UserControl`; `ViewPool` materialises one view per visible item. Slot measurement, node dragging and slot connection are attached behaviors, not per-control event handlers.

This quick start builds a runnable WinForms window with two nodes, their ports, a link and a working camera.

## What you will have at the end

- A `net8.0-windows` project — the tested demo configuration is `net10.0-windows`.
- The seven view roles generated by `VeloxDev.WinForms.Templates`.
- A tree with two nodes, a channel-constrained input port and a visible link.
- Pan, wheel scroll, Ctrl+wheel zoom, node drag and slot connection checked in the running window.
