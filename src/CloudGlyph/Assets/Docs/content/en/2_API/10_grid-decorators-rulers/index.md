# Grid Decorators and Rulers

A grid decorator is the layer between the surface and its content: it paints the canvas grid below the scroll viewer and the floating rulers above it, aligned by offsets the surface pushes. Core defines the data contract and all the arithmetic; the drawing class is generated from an item template or written by hand.

All Core types are in `VeloxDev.WorkflowSystem`. The Razor decorator is in `VeloxDev.WorkflowSystem.AttachedBehaviors`; the XAML decorators are generated by the item-template packs.

## Layer split

| Layer | Types | Responsibility |
|---|---|---|
| Core | `IWorkflowGridDecorator` | The offsets and `RulerBand` contract. |
| Core | `WorkflowSurfaceMath.GridCanvasLeft` / `GridCanvasTop` / `GridFirstLine` / `GridX` / `GridY` | All grid arithmetic. |
| Core | `SurfaceMetricsPush.PushGrid` | Writes offsets and applies the ruler inset. |
| Core | `WorkflowSpatialEx.SetVirtualizeInset` | Keeps nodes under the ruler from being culled. |
| Adapter / template | `WorkflowGridDecorator` (Razor), generated XAML decorator | The drawing class. |
