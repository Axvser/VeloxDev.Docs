# MonoBehaviour — API Reference

Namespace `VeloxDev.TimeLine` hosts the frame-loop manager and its event-argument types; `VeloxDev.MonoBehaviour` hosts the `IMonoBehaviour` contract. Both ship in the `VeloxDev.Core` package. Evidence: source (`Src/Core/VeloxDev.Core/TimeLine/`, `.../Interfaces/MonoBehaviour/`), the source generator (`Src/Generators/VeloxDev.Core.Generator/`), the WPF demo (`Examples/MonoBehaviour/WPF/Demo/`) and the MSTest suite (`Src/Core/VeloxDev.Core.Test/TimeLine/`).
